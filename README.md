# Full Stack CRUD Task Manager

## Description
A full-stack web application that allows users to create, read, update, and delete tasks.

## Tech Stack
- Frontend: React
- Backend: Node.js + Express
- Database: MongoDB

## Features
- Add tasks
- View tasks
- Update tasks (mark complete)
- Delete tasks

## How to Run

### Backend
cd backend  
npm install  
npm run dev  

### Frontend
cd frontend  
npm install  
npm run dev
